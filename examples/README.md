# Examples

Complete CLI commands for a Driverlog task from the
[Downward benchmark collection](https://github.com/aibasel/downward-benchmarks).
Run them from the repository root.

| Script | Purpose |
| --- | --- |
| `asp.sh` | Solve `driverlog/p07.pddl` directly with ASP |
| `abstraction-asp.sh` | Discover and solve an object abstraction of the same task |

```bash
./examples/asp.sh
./examples/abstraction-asp.sh
```
