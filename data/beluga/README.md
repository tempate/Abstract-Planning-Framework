To start the scripts in this folder, please activate the virtual environment in the `TestScript` folder before

The `Arbeit` folder has to be placed into the Documents folder to work properly and I just tested it on my Ubuntu.

The following scripts are in here:
- run_pipeline_for_one_problem.sh -> full pipeline for one instance
- run_all.sh -> batch concrete runs
- run_all_experiments.sh -> full hangar benchmark suite
- run_all_morehangars.sh -> all extended hangar instances
- run_all_more_trailers.sh -> all trailer instances
- trailer_abstraction_run.sh -> trailer abstraction
- trailer_abstraction_run_moretrailers.sh -> extended trailer abstraction
