# plasp

The plasp executable is installed from the official plasp 3.1.1 Linux x86-64
release and is not tracked in this repository. Run the checksum-verifying
installer from the repository root:

```bash
python scripts/install_plasp.py
```

license are available from the [official repository](https://github.com/potassco/plasp).
